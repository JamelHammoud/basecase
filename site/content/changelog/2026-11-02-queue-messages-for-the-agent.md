---
title: Queue messages for the agent
date: 2026-11-02
version: 0.1.2
---

You can now line up your next messages while the agent is still working. Press ⌘Enter, or Ctrl+Enter on Windows, and the message waits instead of joining the run.

Plain Enter still steers the run in progress. Queuing is for the next thing: “now add mounting holes” while the agent is still shaping the bracket.

Queued messages sit in a banner above the composer and send one at a time, each after the run before it ends. Drag one to change the order, click it to edit it, or delete it. Stop pauses the queue rather than dropping it.

Gemini can't steer, so with Gemini every message you send mid-run queues. The queue doesn't survive a reload of the app.
