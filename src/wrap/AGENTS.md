# src/wrap/

Wrap Robot: an imported mesh over a jointed robot becomes one hollow, printable shell per link that clears every joint's range. Before editing here, read:

- [Joints and motion](../../docs/guide/joints-and-motion.md) (§8c), the Character shells bullet
- [Inspector and selection](../../docs/guide/inspector-and-selection.md) (§7a)
- [Performance](../../docs/guide/performance.md) (§0f)

The rules in the root [AGENTS.md](../../AGENTS.md) apply here too. When you change how this area works, update its guide in the same change.
