# Menus, palette and shortcuts

Part of the Basecase guide. [AGENTS.md](../../AGENTS.md) holds the rules every change follows and the index of these files; section numbers (§) are shared across them.

## 11. Menus, Palette & Shortcuts

- **Right-click (`ContextMenu` primitive):**
  - **Part:** the part's name heads the menu; clicking it copies the name. Then Rename, Duplicate, Mirror ▸ (Side, Front, Top, the last one picked checked, §7), Save to Library, Quote Part (desktop only: opens the Agent tab with the part quoted in the composer, `partQuote`), Make a Leader (on a part of a fixed-base arm, §8c), Size Arm to Targets (on a Guide part, §8c), Comment Here, Measure from Here, Align ▸, Drop to Floor, Stack on Part Below, Center on Origin, Reset Rotation, Zoom to Selection, Solid/Cutout/Guide, Subtract Overlapping Cutouts, Ungroup, Update from Onshape (a part of a robot imported from Onshape, desktop only, §8c), Select All, Lock, Hide, Delete.
  - **Part moved by a joint, while simulating:** Fault ▸ (Limp, Weak, Stuck, Laggy, Clear; the active one checked) follows the name (§8d).
  - **Peak torque row** (Simulate tab, §8d): the joint's name heads the menu, then the same Fault ▸.
  - **Several parts** (right-click inside the selection keeps it): Wrap Robot (first, when the selection is one imported mesh and a jointed robot, §7a), Union, Subtract from {first}, Intersect, Add Hinge and Add Slider (exactly two parts: the first is the parent, §8c), Size Arm to Targets (1 to 8 Guide parts in the selection, §8c), Align ▸, Drop to Floor, Center on Origin, Solid/Cutout/Guide (checked only when all match; reference photos keep their role), Group/Ungroup, Update from Onshape (when the selection holds one robot imported from Onshape), Rename (when the selection is one whole group), Duplicate, Mirror ▸, Select All, Save to Library, Delete.
  - **Rename** on a part or group (the menus above, or Rename in ⌘K's Selection group while one part or one whole group is selected) shows Layers and opens that row's rename field (`renameAction` in `partActions.tsx`, `renameTarget` in `layers/layerRows.ts`), opening its group if it's collapsed. It isn't offered while a Case runs, since the sidebar is hidden.
  - Submenus (`submenu` entries) open on hover, flip left near the window edge, shift up to stay above its bottom, and can hold custom content.
  - **Routine step** (Routines view, §8j): Add Step After, Delete (⌫). The Start step has only Add Step After.
  - **Empty canvas:** Add Part, Comment Here, Measure from Here, Add Reference Image, Sketch, Annotate, Delete Marks (with marks), Import, Select All, camera views, Reset View, Add Camera View, Place on Map (desktop only, §12), Collapse / Expand Camera Views (while the scene has camera views), Show Grid, Show Map (checked while a placed map shows), Export STL.
  - **Camera tile** (§8l): the camera's name heads the menu; Look Through, Rename, Lens ▸; stationary cameras add Use Current View and Delete.
  - **Case** (Cases view, §8h): Rename, then for the open Case Compare With ▸ (when another open scene's robot fits) and Export Case Mat (a ground Case, desktop only), then Delete.
  - Select All (⌘A) is in every menu. Like ⌘A and ⌘K, it skips hidden parts and hidden reference photos.
  - Right-drag and two-finger press-drag pans never open the menu. macOS fires `contextmenu` on press, so the canvas menu opens on release, and only if the pointer moved 5px or less (`menuPressRef`). Windows' release-then-`contextmenu` order is handled the same way. A two-finger tap within 400ms of a wheel event (scroll, pinch or momentum) is ignored too (`TRACKPAD_TAP_GRACE_MS`). Scrolling closes an open menu.
- **⌘K command palette:** every part, model, tool, view and scene action, behind a “Search commands” field. A command that brings up a tab or view is Show ⟨its name⟩, in the Panels group, and every sidebar view and right-panel tab but two has one: Show Layers, Show Library (`SIDEBAR_VIEWS` in `viewCommands.tsx`), Show Cases, Show Routines, Show Operate, Show Pose, Show Simulate (while the tab shows), Show Build and Show Agent. Parts is Find Parts (⌘F), which also puts the cursor in its search, and Inspect has none, since a Show Inspect beside ⌘I's Show Inspector (which shows or hides the whole right panel) would read as the same command. Layers, Library, Cases, Routines and Operate open the sidebar through `showLeftTab` (`workspace/showView.ts`). Show Robots and Show Objects (`PARTS_SECTIONS`) open Parts scrolled to that section, through `showPartsSection`. Build Along (Scene group) plays the build guide on the canvas. Make Build Guide (Scene group, while no guide is made and a solid part is in the scene) makes it and opens the Build tab; once made, Open Build Guide opens it, and Update Build Guide joins it while the guide is out of date; none show while a guide is being made (`guideCommands` in `buildCommands.tsx`). Simulate (Simulate group, while the scene has a movable joint) opens the Simulate tab and starts the simulation, and Stop Simulation takes its place while it runs (`simCommands.tsx`). Buy All (Scene group, while the bill of materials has a line with an ASIN) opens the Amazon cart filled from it (§8b). Add Hinge and Add Slider are listed while exactly two parts are selected. Coach ⟨skill⟩ (Simulate group, desktop) is listed for each ready Motor Kit skill; it opens the Simulate tab and scopes its Teach field to that skill, and Compare ⟨skill⟩ and Undo Coach ⟨skill⟩ follow a coached row's menu (`coachCommands.tsx`, §8i). Run Case and Rename Case (Simulate group) appear while a Case is open, with Compare with ⟨scene⟩ for each other open scene whose robot fits it (§8h). The Agent group has each slash command (Teach a Skill, Make a Routine, Make a Case, Simulate the Scene, Operate the Robot, Run Checks), which opens the Agent tab with `/<command> ` in the composer, New Chat, which opens the Agent tab on a new chat, and the composer's Attach Images and Attach Sketch, which open the Agent tab and then the picker or the sketch pad (`slashPaletteCommands.tsx`; none of them in the web demo). Make It Pass (Agent group) appears while the open Case's Checks row fails or warns, and puts `/pass ⟨Case⟩` in the composer the same way. The Operate group (§8k) has Connect Emulated Robot, Set Up Servos and Calibrate Servos, each opening the Operate tab first; Set Up Servos is listed only while it can start, and Disconnect Robot takes Connect Emulated Robot's place while a robot is connected. Live inputs (§8h): Drive with Camera (Simulate group, for humanoids and fixed arms while not driving; Esc stops it and turns the camera off), Pair Phone (Simulate group; Unpair Phone while a phone is pairing or paired; not in the web demo) shows the pairing QR code, and Esc closes it and ends the pairing. A command that has nothing to act on is left out rather than doing nothing: Export STL, Export 3MF Plates and AirDrop while the scene has no parts, Export Robot Package until it has a movable joint (the Export menu greys out the same ones). The part commands both lists share (Select All, Duplicate, Save to Library, Delete, Drop to Floor, Stack on Part Below, Center on Origin, Zoom to Selection, Group, Ungroup, Union, Intersect, Add Clearance Hole, Wrap Robot, Size Arm to Targets, Reset View, Reset Rotation, Lock, Hide and Quote Part) read one table, `workspace/partActions.tsx` (`selectionActions`, `onePartActions`), through `menuEntry` and `paletteCommand`, so each has one label, shortcut and icon, and a new shared part command goes there once. Align, Mirror and Update from Onshape are in both lists too, outside the table (`components/alignActions.ts`, `mirrorCommands.tsx`, `onshapeCommands.tsx`). The rest of the part menu is right-click only, built in `contextMenuItems.tsx`: the name heading, Solid, Cutout and Guide, Subtract Overlapping Cutouts, Subtract from ⟨part⟩ and Ungroup ⟨group⟩ (⌘K has a plain Subtract and Ungroup), and Fault ▸. Commands on the selection follow the right-click menu, through one table (`canRunOnSelection` in `workspace/selectionNeeds.ts`, applied in `WorkspacePalette`): Copy, Cut, Duplicate, Mirror (across the last plane picked), Subtract, Align, Drop to Floor, Center on Origin, Zoom to Selection, Save to Library and Delete need a selected part, Add Clearance Hole a selected hardware part (Add Clearance Holes for more than one), Stack on Part Below exactly one, Group, Union and Intersect two, Spread Along X, Y and Z three, Ungroup a part in a group, and Select All a part in the scene. Lock, Hide (Unlock and Show once on), Quote Part (desktop only) and Reset Rotation (only while the part is turned) act on one selected part, as in its right-click menu. Reset View is in the View group.
- **Slash commands** (`src/agent/slashCommands.ts`, `components/agent/useSlashMenu.ts`, `SlashMenu.tsx`): typing `/` at the very start of the composer opens a menu above it (`PopoverMenu` with `MenuItem`s: the command's icon, the command, and its name muted, the icon and name ⌘K's Agent group shows, both read from `slashCommands.ts` and `slashIcons.tsx`): `/train`, `/routine`, `/case`, `/simulate`, `/operate`, `/check`, filtered as you type (prefix matches first). ↑ ↓ move (wrapping), ↩ or Tab inserts `/<command> ` and keeps focus, Esc closes it and leaves the text; a click in the composer keeps it open. The same list opens from the composer's + menu → Commands, which keeps whatever is typed and puts the command in front of it (`withSlash`). The agent reads each one through the prompt's Slash commands section.
- **Shortcuts:**
  - **One table.** Every key that works across the workspace, in the scene tabs or in the agent composer is a row in `electron/shortcuts.json`: a command id (the native menu's id where there is one), where it works (`canvas`, `annotate` while Annotate is on, `tabs`, `composer`, `timeline` while the try timeline is open, or `clipboard` for ⌘C / ⌘X / ⌘V, which arrive as clipboard events) and its keys as shown (`⇧⌘Z`, `⌃Tab`, `⌘1–8` for a range). The handlers find their command through it (`shortcutFor` in `src/app/shortcuts.ts` for `useWorkspaceKeys`, `tabShortcuts` and the composer), the native menu reads its accelerators from it (`menuAccelerator` and `tabChord` in `electron/shortcutKeys.mjs`), and ⌘K, right-click menus and tooltips show `keyFor(id)`. A key matches its modifiers exactly (⇧F isn't F, and ⌥ is never ignored); ⌘ means ⌘ or Ctrl, and only `?` and `,` ignore Shift, since some layouts need it to type them (`SHIFT_FREE_KEYS`). Settings → Shortcuts lists each row by id (`SHORTCUT_GROUPS` in `src/components/shortcutGroups.ts`, §6a); rows that describe a pointer gesture (Space-drag, ⇧-click) or what the text field does on its own (⇧↩, `/`) keep their keys there. `shortcutGroups.test.ts` presses every listed key and fails when one reaches no handler, when a handled key isn't listed, or when a described row names no gesture; `electron/app-menu.test.mjs` fails on a menu accelerator that isn't from the table. A new shortcut is a table row, a handler under its id and a pane row, in one change. Keys that belong to one mode (Build Along, the Try timeline, the Routines view, a running Case's Esc, dialogs) stay with that mode and aren't listed.
  - There's no ⌘S: scenes save themselves (§5a). Imported and duplicated scenes are written at once, and the only unsaved scenes are a blank one and the untouched first-launch rover, which stay unsaved on purpose.
  - Tools: V (or W)/E/R/C/M, D measure, N annotate, A shapes. P opens the Pose tab (on a robot, or in a scene with a skeleton).
  - Skeleton (§8c): ⌘K Edit Skeleton turns the skeleton on and opens the Pose tab. ⌘K Size Arm to Targets, with Guide parts selected, sizes an arm to reach them and opens it there. Dragging a joint ball moves it and everything below it in 1 mm steps; Shift moves freely, ⌥ moves the joint alone; ⌘Z undoes a whole drag.
  - Placement and view: F floor, S stack, Z zoom, 1–4 views, ⇧I reference images, ⇧V camera views. Hold ⌘ (Ctrl on Windows) while dragging a part or a tile to move it without snapping to ports (§12), and Shift to move it off the grid.
  - Edit: ⌘Z / ⇧⌘Z (or ⌘Y), ⌘C / ⌘X / ⌘V, ⌘D, ⌫, ⌘A select all, ⌘G / ⇧⌘G group, Esc (ends a Set Up Servos walk, §8k → closes draft → thread → comment mode → measurement → Measure tool → Annotate → picking a joint axis → Sculpt, or Sketch and Import SVG while they hold nothing to lose → selection).
  - A running Case (§8h): Esc leaves (the first Esc stops driving), ⌘K and ⌘, work, and ⌘Z, ⌘⇧Z, ⌘Y and ⌘I work even while driving (undo and redo the agent's code writes and stop at any other edit, show or hide the agent); no other editing or panel key runs. In ⌘K there, every command but Drive, Stop Driving, Start Over, Try ⟨Case⟩, Export Dataset, Publish to Hugging Face, Drive with Camera, Pair Phone and Unpair Phone leaves the running Case first.
  - Build Along (§8b): ← / → previous and next step, Esc closes; the workspace's other keys are off while it's open.
  - Sketch plane (while it has focus, §8): typing a number with a shape started opens its length (a line, then Tab for the angle), width (a rectangle, then Tab for the height) or diameter (a circle); Enter places it, Esc closes the fields, then cancels the shape, then clears the selection, then drops the tool, then leaves Sketch if nothing is drawn. With one segment selected, typing a number or Enter edits its dimension. ⌫ deletes the selection. ⌘Z / ⇧⌘Z undo and redo sketch edits; the plane owns its edits through `data-own-edits` like the Routines view, and a reopened sketch's undo is the scene's.
  - Routines view (while it has focus, §8j): ⌘Z / ⇧⌘Z undo and redo Routine edits (the view owns its edits through `data-own-edits`, so the scene's history is untouched), ⌫ deletes the selected step, Esc clears the selection, ↑ ↓ Home End move through the step menu. ⌘↩ runs the open Routine whenever the Routines view is open.
  - Try timeline (while it's open, §8h; the table's `timeline` scope, handled by `timelineKeyHandlers` in `useTimelineKeys`): ← → one frame, ⇧← ⇧→ one second, Home End, Space play and pause, [ ] slower and faster (0.25× to 4×), Esc closes it (and keeps the selection). ⇧-drag on a lane loops that range; a ⇧-click drops it. While a try plays, its Case's console shows (§8h Playback), and Esc there closes the playback before it leaves a running Case.
  - A real try's paths (after its Replay, §8h): Esc clears them; the key still does whatever else Esc does there.
  - App: ⌘F Find Parts, ⌘P Print (Print mode), ⌘, Settings, ⌘B / ⌘I panels, ? Settings → Shortcuts (§6a).
  - Scenes: ⌘T new, ⌘W close, ⇧⌘T reopen, ⌃Tab / ⇧⌘] next, ⌃⇧Tab / ⇧⌘[ previous, ⌘1–⌘9 (§5a).
  - **Copy, cut and paste** work on the clipboard events (the Edit menu's native roles, so text fields keep native editing). Copied parts live in memory, shared by every tab; the system clipboard holds only a marker type (`application/x-basecase-parts`), so ⌘V pastes parts only while nothing newer was copied, and a pasted image still becomes a reference plane. Pastes keep names, get new ids and groups, and drop `jointId`; Duplicate names its copy as §3b-17 says (`duplicateParts`). In the same scene each paste steps 15 mm (like Duplicate); after a cut or in another scene the first paste lands in place. Cut reads “Cut ⟨name⟩ · Undo”.
  - Every new command gets a palette entry, and a tooltip shortcut when it has one.
