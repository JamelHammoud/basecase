# Accounts

Accounts worth opening, which the lead weighs when it plans integrations: the market lane reads public pages only and signs up for nothing. Rules: [README](README.md).

| Service | Plan | What it would teach | Proposed |
|---|---|---|---|
| Onshape | Free | What Onshape's own URDF export writes for a test assembly: which mates become which joints, whether subassembly mates keep their limits, and how frames and tool center points appear, beside what Import Robot reads from the same link ([integrations](integrations.md#onshape)) | 2026-11-13 |
| Fusion | Personal use | Which formats the personal licence exports today and what fusion2urdf writes from a jointed design ([integrations](integrations.md#fusion)) | 2026-11-13 |
| Shapr3D | Basic (free) | What "Basic resolution" 3MF and STL exports look like when opened through Import, whether the 3MF keeps part names and colours, and how it hands a multicolour model to Bambu Studio ([competitors](competitors.md#shapr3d)) | 2026-11-13 |
| DigiKey | Developer account and sandbox application | Test a small BOM with exact manufacturer part numbers, duplicate lines, packaging and on-hand quantities through CreateList and AddPartsToListId, then inspect unmatched parts and the resulting MyLists page. Public setup requires My DigiKey registration ([setup](https://developer.digikey.com/), [integration](integrations.md#digikey)) | 2026-11-15 |
| Prusa Connect | Free for Prusa owners | Compare the legacy printer API-key upload setup with the OAuth and team-based upload in published PrusaSlicer source, including whether an uploaded file is queued or starts printing. This establishes which cloud handoff to build without assuming PrusaLink compatibility ([comparison](https://help.prusa3d.com/article/prusa-connect-and-prusalink-explained_302608), [integration](integrations.md#prusa-connect)) | 2026-11-15 |
