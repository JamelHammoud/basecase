title: Ask the agent for a Case app
date: 2026-11-13

You can now tell the agent in one sentence what you want to do with a robot, and it builds a Case app. The Case opens in Run Case, laid out for that task.

It works in the agent panel of the desktop app, with or without `/case`. Say "drive this rover with a gamepad while I watch its front camera". The agent makes a Case that drives with the gamepad. It puts the front camera left of the canvas, and a map and the speed on the right.

When the scene has no robot, the agent first imports the one you named, such as a Unitree G1. It picks the input you name, or the keys when you name none. Every camera you mention gets a panel, and a game gets a timer and a score. The world stays an open floor unless you describe one.

Keys and a gamepad are the only inputs today. Ask for your Mac's camera, a phone, MIDI, a leader arm or voice, and the agent says it can't connect that yet. It builds the rest with the keys in its place.

Steps are in [Make a Case](/help/make-a-case).
