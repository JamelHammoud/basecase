## Code panel reference
A code panel is one HTML document, script and style inline, at most 256 KB, at most 4 per Case. It runs in a sandboxed frame with no network, storage, parent page or navigation; window.basecase is its only way out.
- basecase.signals(names, (values, time) => …) → unsubscribe. names: one name or up to 32, * for one segment. Calls back with { name: number | string[] } at most 20 times a second, at most 16 subscriptions.
  Signals: time; joint.<id>.target | position | effort (degrees or mm, effort in N·m); robot.height | tilt | speed | travelled | x | z; probe.<name>; input.<source>.forward | left | turn | lift | grip; goal.passed | margin | failed (failed is a list); the console’s own signals.
- basecase.drive({ v: [forward, left, turn], aux?: [lift, grip], target?: [x, y, z] }) drives the robot: v and aux each −1 to 1; target is a point for an arm’s hand in scene mm, y up. drive(null) lets go. Needs code in the console’s input.
- basecase.event(name, value = true) sends a named event to the Case’s logic: name a plain word, value a boolean, a number or up to 200 characters.
- basecase.action(name) → Promise<{ ok, problem? }>. name: try | end-try | drive | stop | start-over | reset; refused when it can’t run now.
- basecase.world.set(name, { pose?: { position?: [x, y, z], rotation?: [x, y, z] }, visible?, color? }) moves, shows, hides or recolors a world object the Case marks movable: position in the Case’s own mm, rotation in degrees, color #rrggbb. At most 60 calls a second; the try records each change.
- basecase.frames(camera, { width?, fps? }, (bitmap) => …) → stop. Sends a camera view as ImageBitmaps: width 16 to 640 px (default 320), height three quarters of it, fps 1 to 15 (default 10), at most 4 streams.
- CSS variables: --bc-bg, --bc-canvas, --bc-panel, --bc-raised, --bc-surface, --bc-accent, --bc-accent-hover, --bc-red, --bc-green, --bc-line, --bc-ink, --bc-ink-2, --bc-ink-3, --bc-font, --bc-mono, --bc-text, --bc-text-control, --bc-text-small, --bc-control, --bc-radius, --bc-radius-control, --bc-gap, --bc-inset. The body starts transparent in the studio’s font, size and ink.
- The studio keeps the first 10 uncaught errors with their lines, the first 20 console lines and the calls it refused. More than 240 messages a second are dropped. A panel that throws while it loads, says nothing for 10 s or stops answering for 2 s is unloaded.
- Esc and ⌘K reach the studio; every other key stays in the panel while it has focus.
