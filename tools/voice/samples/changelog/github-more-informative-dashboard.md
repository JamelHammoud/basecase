# A more informative GitHub dashboard

November 10, 2026

Since the new dashboard experience became the default, we’ve heard from developers that it used too much space to show too little. Generous padding, wrapped titles, and a low default item count meant extra navigation just to see what needed attention. In addition, “Agent sessions” remained visible even if users didn’t have any agent sessions available.

This update makes the dashboard more compact and easier to scan:
- Pin the Feed or Home tab as your default view.
- Reduced padding across pull request, issue, and agent session lists so you can see more at a glance.
- Long titles now stay on one line, with the full text available if you need it.
- Pull requests and issues now show six items by default instead of three, all while preserving any custom selections you’ve already made.
- The agent sessions section is hidden if no agent sessions exist on the user’s account.
