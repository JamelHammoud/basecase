You can now run a Case in a window laid out for it. Run Case fills the window with the open Case and puts the robot in the middle, with whatever that Case needs around it: camera feeds, live joint plots, a timer, a score or a Reset button.

Open it with the expand button in the Case's header in the Simulate tab, or with Run Case in ⌘K. Done or Esc takes you back to the scene, the selection and the camera as you left them.

## The Console

A Case can carry a console that says how it runs: which inputs drive it, which panels it shows, and the columns of fixed widths those panels sit in around the canvas.

Inputs can be keys, a gamepad, a phone, the computer's camera or a code panel, and the console can also name signals of the Case's own. Panels come in nine kinds: camera, value, plot, table, button, list, text, a top-down map and code. Each one reads named live signals, like joint efforts, timers and scores.

A block game, for example, puts Time and Score on the left and Try It, Reset and the tries on the right.

![A block game console during a try: Time counting down and Score left of the arm, and Try It, Reset and the running try on the right](/changelog/run-a-case/console.png)

## Code Panels

A code panel is the Case's own web page, like a joystick drawn on a canvas or a speed readout over the robot. It drives the robot the way a gamepad does and sends events to the Case's logic.

Code panels run sandboxed, with no network, and each can keep one small value on this computer, such as a high score. If one stops answering for 2 seconds, it closes and says so.

![A rover Case running with a joystick in the right column and its speed and tilt over the canvas](/changelog/run-a-case/code.png)

A code panel can also move, light or hide the Case's movable objects, and it can watch a camera.

![A rover Case running, with a code panel showing the Scene camera and the target its code moved and lit red](/changelog/run-a-case/world.png)

## Cases Without a Console

A Case without a console runs with its cameras on the left, and the brief, failures, servos and tries on the right.

Ask the agent in words, like "a rover on a gamepad with its front camera," and it opens the Case running. A leader arm and policies are refused as inputs until they can drive a Case.

Read [Run a Case](/help/run-a-case) in the help center for the steps.
