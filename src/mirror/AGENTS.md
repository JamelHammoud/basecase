# src/mirror/

Mirroring: the one module the person's Mirror command (right-click, ⌘K, the multi-selection Inspector) and the agent's `mirror_parts` both go through. Plain data in, plain data out: planes, part placement and geometry, mates, twin joints. Before editing here, read:

- [Inspector and selection](../../docs/guide/inspector-and-selection.md) (§7–8): what Mirror does to each kind of part, mates, joints and frames
- [Agent](../../docs/guide/agent.md) (§9): `mirror_parts`, placement by datum

The rules in the root [AGENTS.md](../../AGENTS.md) apply here too. When you change how this area works, update its guide in the same change.
