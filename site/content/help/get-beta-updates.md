Switch your updates to the beta channel to get new versions of Basecase before they're released to everyone.

Beta updates are off by default. When you turn them on, you also get every stable release.

## Turn on beta updates

1. On a Mac, choose **Basecase** ▸ **Get Beta Updates**. On Windows, click **Menu**, then choose **Help** ▸ **Get Beta Updates**.

   A check mark appears next to the item. Basecase checks for a newer beta right away and downloads it if there is one.

2. When the blue arrow appears above **Settings** in the view rail, click it to restart and install the update.

## Go back to stable releases

1. Choose **Get Beta Updates** again to remove the check mark.

   Basecase never installs an older version over a newer one, so you keep the beta you have until a stable release with a higher version number is available.

To learn how to install any update, see [Update Basecase](/help/update-basecase).
