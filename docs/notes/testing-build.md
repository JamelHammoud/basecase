# Build evidence navigation

Current coverage lives in [Build](../guide/build.md#testing-coverage), [Inspector](../guide/inspector-and-selection.md) and [Printing](../guide/printing.md). Shared test policy, selection and harness contracts remain in [Running and testing](../guide/running-and-testing.md#0e-tests).

Add evidence to the implementation owner's note below. Keep a feature and its repair history together. Reuse its section for later observations and restoration evidence. This page is navigation, not an incident log.

| Owner | Evidence |
| --- | --- |

| Frozen builds, groups, allocation, repair and photographs | [Assembly](performance-assembly.md#frozen-individual-builds) |
| Shared parameters, supported Sketches and imported flat parts | [Sketch](performance-sketch.md#shared-dimension-preparation) |
| Cable stock, route editing and Current replay | [Wiring](performance-wiring.md#editable-cable-route-work) |
| Fit plates, cradles, replacement fingers and print delivery | [Printing](performance-printing.md#comparison-fit-plates) |
| Checks, Falls and dimensional tolerances | [Engineering](performance-engineering.md#requested-blocker-repairs) |
| Passive robot joints | [Joints and motion](testing-joints-and-motion.md#passive-robot-joints) |

Historical summaries spanning owners remain in [Node-side evidence](node.md#windows-board-and-sketch-file-flows). Each summary links to its separately owned paths. New subsystem observations belong in those paths, rather than extending the mixed summary. [The migration replay](performance-documentation.md#build-evidence-ownership-replay) records preservation, conflict inputs and measurement limits.
